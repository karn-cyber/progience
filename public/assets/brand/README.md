# Progience logo assets

These PNG assets were extracted from the official Progience Brand Guide.

- `progience-logo-primary.png`: navy horizontal wordmark for white or very light surfaces.
- `progience-logo-reversed.png`: white horizontal wordmark for brand navy or other approved dark surfaces.
- `progience-mark-primary.png`: navy standalone `P` mark for white or very light surfaces.
- `progience-mark-reversed.png`: white standalone `P` mark for brand navy or other approved dark surfaces.
- `progience-favicon-32.png`, `progience-favicon-192.png`, and `progience-favicon-512.png`: responsive browser icons using the reversed mark on a self-contained brand navy tile.
- `progience-apple-touch-icon.png`: 180px home-screen icon using the same high-contrast treatment.

The colour artwork inside the `P` is retained exactly as supplied. Do not recolour, distort, crop, or place the logos on a surface that reduces contrast. Clear space should be added in layout code rather than baked into the PNG files.
